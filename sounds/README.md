# Timer sounds

Put your own timer sounds here, with these exact names:

| File | When it plays |
|---|---|
| `match-start-cue.mp3` | The moment the Match clock starts, after the 3-2-1 countdown. |
| `driver-switch-cue.mp3` | At 0:35 and 0:25, when the driver switch window opens and closes. |
| `countdown-tick-cue.mp3` | Countdown ticks (optional). |
| `end-buzzer-cue.mp3` | When the Match ends. |

Any file that is missing uses Vexifiy's built-in sound. Audio files in this folder are ignored by git, so recordings you have are never uploaded to GitHub.
